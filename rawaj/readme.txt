An Arabic-first WooCommerce FSE WordPress theme with foundational design token system.

== Description ==

Rawaj is a premium Arabic-first Full Site Editing (FSE) WordPress theme designed for WooCommerce e-Commerce. Built with modern design tokens and following WordPress best practices.

= Features =

* **Design Token System**: Complete theme.json with14-color palette, 2 font families, 8 font sizes, 8 spacing tokens
* **RTL-First**: Designed from the ground up for Arabic and other RTL languages
* **Light/Dark Mode**: Built-in support for both color schemes
* **WooCommerce Ready**: Pre-styled product, cart, and checkout pages
* **Typography**: Cairo for headings, Tajawal for body text (Google Fonts)
* **Performance**: Optimized for Lighthouse≥90 Performance, ≥95 Accessibility

= Typography =

The theme uses Google Fonts:
* Cairo (headings): Weights 400, 500, 600, 700, 800, 900
* Tajawal (body): Weights 400, 500, 600, 700

== Installation ==

1. Upload the theme folder to `/wp-content/themes/`
2. Activate the theme through the 'Themes' menu in WordPress
3. Go to Appearance → Editor to customize using the Site Editor
4. Alternatively, use Global Styles to modify colors, fonts, and spacing

== Frequently Asked Questions ==

= How do I customize colors? =

Go to Appearance → Editor → Styles → Colors to modify the color palette using WordPress's Global Styles interface.

= How do I switch to Dark Mode? =

The theme automatically respects your system's color scheme preference (prefers-color-scheme). You can also manually override colors in Global Styles.

= Does this theme work with WooCommerce? =

Yes! Rawaj includes styled WooCommerce blocks for products, cart, and checkout pages.
